# Project CO3009 – Two-Road Traffic Light System

## 1. Project Description
This project implements a two-road traffic light system using the NUCLEO-F103RB board (STM32F103RB).

Course: Microprocessors – Microcontrollers (CO3009).

## 2. Main Features
- Automatic traffic light control
- Manual traffic light control using push buttons
- Red, Green, and Amber timing adjustment
- Temperature and humidity display using DHT20 and LCD
- O(1) task scheduler

## 3. Development Tools
- STM32CubeIDE
- STM32 HAL Library
- Git and GitHub

## 4. Project Structure
- `TrafficLight/Core/Inc/`: Header files
- `TrafficLight/Core/Src/`: Source files
- `TrafficLight/Drivers/`: STM32 HAL drivers
- `TrafficLight/TrafficLight.ioc`: STM32CubeIDE configuration
